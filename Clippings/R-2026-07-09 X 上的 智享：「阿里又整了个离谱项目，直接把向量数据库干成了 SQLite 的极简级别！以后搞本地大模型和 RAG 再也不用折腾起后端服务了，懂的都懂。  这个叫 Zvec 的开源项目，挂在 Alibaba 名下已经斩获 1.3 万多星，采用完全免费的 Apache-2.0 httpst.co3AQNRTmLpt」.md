## 對話

阿里又整了个离谱项目，直接把向量数据库干成了 SQLite 的极简级别！以后搞本地大模型和 RAG 再也不用折腾起后端服务了，懂的都懂。 这个叫 Zvec 的开源项目，挂在 Alibaba 名下已经斩获 1.3 万多星，采用完全免费的 Apache-2.0 协议。它是阿里内部打磨的底层向量引擎开源出来的，主打“纯本地、内嵌式”。没有任何花里胡哨的服务器配置，不需要网络开销，就像调个普通的库一样，直接插进你的应用代码里就能原地起飞。 核心爽点： 安装贼粗暴：直接 pip install zvec 搞定，零配置零服务，开箱即用。 性能快得离谱：C++ 写的硬核底座，毫秒级通吃几十亿向量搜索。 功能够生猛：同时支持密集向量、稀疏向量，甚至自带原生全文检索和标量过滤。 白嫖党狂喜：全本地运行极度省资源，断电不丢数据，破笔记本和边缘设备都能顺畅跑。 做本地 AI 应用、自动化 Agent 和个人知识库的兄弟们直接上。还在等啥，自己去看。 GitHub： [github.com/alibaba/zvec](https://t.co/I4vJFGvmGr) 官网： [zvec.org/en/](https://t.co/aUHcMEHzZI)
