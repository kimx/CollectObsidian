# ⚡ Fleeting Notes — 靈感速記

靈感速記用於**快速捕捉**腦中閃現的想法，無需完整格式，重點是不遺漏任何靈感。

## 整理原則

- 每週至少回顧一次 Fleeting Notes
- 有價值的想法 → 整理成 `Notes/Permanent/` 永久筆記
- 已整理的 Fleeting Note → 加上 `#status/done` 標籤或刪除

## AI 協作提示

- 將一批 Fleeting Notes 貼給 AI，讓它協助**分類、整合與擴展**
- 讓 AI 識別多則 Fleeting Notes 之間的**共同主題**
