# 🌱 Permanent Notes — 永久筆記

永久筆記（常青筆記）是知識庫的核心。每則筆記表達**一個清晰的概念或見解**，用自己的話寫成，並與其他筆記建立雙向連結。

## 寫作原則

1. **一筆記一概念** — 每則筆記只聚焦一個想法
2. **用自己的話** — 不是複製貼上，而是消化後重新表達
3. **建立連結** — 透過 `[[Wiki Link]]` 連接相關筆記
4. **持續迭代** — 隨著理解加深，回來更新筆記

## AI 協作提示

- 把草稿（Fleeting Note）貼給 AI，請它協助**改寫得更清晰、更原子化**
- 讓 AI 建議此筆記應連結到哪些現有筆記
- 讓 AI 識別知識庫中是否已有類似筆記，避免重複
