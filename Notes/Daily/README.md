# 📅 Daily Notes — 每日筆記

每日筆記（日誌）用於記錄當天的任務、想法、反思與重要事件。

## 使用方式

使用 Obsidian 內建的「Daily Notes」或「Periodic Notes」插件，搭配 `Templates/daily-note` 模板自動建立。

## 命名規則

```
YYYY-MM-DD.md
```

## AI 協作提示

- 讓 AI 對一週的 Daily Notes 進行**週回顧摘要**
- 讓 AI 從 Daily Notes 中提取反覆出現的主題，建議寫成 Permanent Notes
