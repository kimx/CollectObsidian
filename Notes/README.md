# 📝 Notes — 個人筆記

個人筆記分為三個層次，對應 Zettelkasten 方法論：

| 子目錄 | 說明 | 生命週期 |
|--------|------|----------|
| `Daily/` | 每日筆記，記錄當天的思考、任務與反思 | 每天建立 |
| `Fleeting/` | 靈感速記，快速捕捉腦中閃現的想法 | 即時記錄，定期整理 |
| `Permanent/` | 永久筆記，深度整理後的「常青筆記」 | 長期維護 |

## 筆記流程

```
閱讀/思考
    ↓
[Fleeting Note] — 快速記下想法
    ↓
定期回顧整理
    ↓
[Permanent Note] — 用自己的話重新表達、建立連結
    ↓
連結至 Areas / Resources
```
