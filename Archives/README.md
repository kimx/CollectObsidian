# 🗄️ Archives — 封存

此目錄存放**已完成或不再活躍**的內容，以保持其他目錄的清爽。

## 結構

```
Archives/
├── Clippings/         # 過期或已處理的剪藏
└── Notes/             # 過期筆記
```

## 封存原則

- **Clippings**：超過 1 年未回顧的剪藏定期移入
- 封存內容**不刪除**，只移動，保留完整知識軌跡

## AI 協作提示

- 讓 AI 定期掃描各目錄，建議哪些內容適合移入封存
- 讓 AI 對封存的專案產生**回顧報告**（學到什麼、下次改進點）
