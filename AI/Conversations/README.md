# 💬 AI Conversations — AI 對話紀錄

此目錄存放與 AI 工具的重要對話紀錄，方便日後回顧或延續。

## 命名規則

```
YYYY-MM-DD-<主題>.md
```

## Frontmatter 規範

```yaml
---
title: 對話主題
date: YYYY-MM-DD
ai_tool: ChatGPT-4o
related_notes:
  - "[[相關筆記]]"
tags:
  - type/ai-output
summary: 此對話解決了什麼問題或得到什麼結果
---
```

## 使用建議

- 只記錄**有價值的對話**（解決了問題、得到重要見解）
- 在對話結束後，將關鍵結論提取到對應的 `Notes/Permanent/` 或 `Resources/` 筆記中
- 使用 `related_notes` 連結到受此對話影響的筆記
