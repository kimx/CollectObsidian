# 💬 文章摘要 Prompt

## 使用情境

當 `Clippings/` 中累積了文章，需要快速了解重點時使用。

## Prompt 內容

```
請閱讀以下文章，並提供：

1. **一句話摘要**（不超過 30 字）
2. **三個重點**（條列式，每點不超過 50 字）
3. **對我的啟發**（請根據文章內容提出 1-2 個可行動的建議）
4. **相關關鍵字**（5 個，適合作為 Obsidian 標籤）

---
[貼上文章內容]
---
```

## 使用範例

- **輸入：** 一篇關於深度學習的技術文章
- **輸出：** 摘要、重點條列、建議（如「嘗試用 PyTorch 實作此架構」）、標籤（`#AI`、`#DeepLearning` 等）
