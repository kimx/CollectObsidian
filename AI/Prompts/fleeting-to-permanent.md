# 💬 靈感整理成永久筆記 Prompt

## 使用情境

當累積了一批 `Notes/Fleeting/` 靈感速記，需要整理成清晰的永久筆記時使用。

## Prompt 內容

```
以下是我的一些零散想法和靈感速記，請協助我整理：

[貼上 Fleeting Notes 內容]

請幫我：
1. 識別其中的**核心主題**（每個主題一則筆記）
2. 為每則筆記提供：
   - 清晰的**標題**（概念型，如「遠距工作提升專注的三個條件」）
   - 用**自己的話**重新表達的內容（100-200 字）
   - 建議連結的**相關概念**（可能是其他筆記的標題）
3. 用 Markdown 格式輸出，包含 YAML Frontmatter
```
