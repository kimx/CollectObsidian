# 📄 AI Summaries — AI 摘要輸出

## 命名規則

```
YYYY-MM-DD-<主題或來源>.md
```

範例：
- `2026-05-06-AI知識庫架構總結.md`
- `2026-05-06-Clippings-科技趨勢綜合報告.md`
