# 2026-05-19 Tools 綜合摘要

## 摘要

這四篇工具筆記可串成一條完整知識工作流：先用 ShareX 快速採集素材，再用 SuperSplat 處理 3D 內容，接著以 Obsidian AI 做語義檢索與問答，最後用 html-anything 把 Agent 產出整理成可分享的 HTML 成品。整體價值在於把「收集、整理、查詢、交付」連成可重複流程。

## 重點

- 工具能力已從單點使用走向流程整合
- 採集（ShareX）是知識輸入的起點
- 查詢（Obsidian AI）降低回找筆記成本
- 交付（html-anything）補上展示與輸出品質
- 不同工具可按需求組成個人工作流

## 分篇整理

### 1) ShareX 免費開源截圖工具

- 適合做網頁與螢幕內容採集
- 支援多種擷取與上傳整合
- 可作為 Clippings 前置入口

### 2) SuperSplat 3D Gaussian Splat 編輯器

- 聚焦 3D Gaussian Splat 的編輯需求
- 提供可視化處理流程
- 適合影像與 3D 展示相關情境

### 3) Obsidian AI 側邊欄與語義搜尋

- 以插件方式提供聊天與語義搜尋
- 讓筆記查找與問答更直覺
- 降低使用 AI 助手的上手門檻

### 4) html-anything Agent HTML 生成工具

- 可把 Agent 輸出轉成高品質 HTML
- 支援多種 Skills 與輸出格式
- 強化成果對外分享與交付效率
