# 🎯 Areas — 持續關注的領域

此目錄存放**長期持續關注、沒有明確結束日期**的責任範疇。

## 典型領域範例

```
Areas/
├── Health.md          # 健康管理
├── Finance.md         # 財務規劃
├── Learning.md        # 持續學習
├── Career.md          # 職涯發展
├── Relationships.md   # 人際關係
└── Home.md            # 家庭生活
```

## 與 Projects 的差異

| | Projects | Areas |
|---|---|---|
| 有截止日期 | ✅ | ❌ |
| 有完成狀態 | ✅ | ❌ |
| 範例 | 「完成讀書計畫」| 「持續學習」|
