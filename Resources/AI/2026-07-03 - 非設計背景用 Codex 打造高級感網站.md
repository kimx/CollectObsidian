# 📎 非設計背景用 Codex 打造高級感網站

## 摘要

> 不要一上來讓 Codex 寫頁面，先讓它整理 DESIGN.md，把「感覺」拆成可執行的規則後再實作。這套流程配合參考庫挑選、taste-skill 工具集與 Cowart 無限畫布，讓非設計背景的人也能打造有個人表達、去除 AI 味的高級感網站。

## 重點

- **DESIGN.md 優先**：讓 Codex 整理頁面氣質、顏色、字體、首屏排版、按鈕樣式、動效與「不要做什麼」，確認後才開始寫程式碼
- **三類參考來源**：
  1. [Refero Styles](https://styles.refero.design/)：現成風格 DESIGN.md + 顏色字體規則，最省事
  2. [web-to-design-md](https://github.com/Paidax01/web-to-design-md)：提取真實網站設計規則，轉成 Codex 可讀格式
  3. Mobbin / Land-book / Collect UI / Minimal Gallery：探索審美方向
- **taste-skill 選用**：有參考圖用 `image-to-code`；沒有用 `imagegen-frontend-web` 先出意向圖；去 AI 味用 `design-taste-frontend`
- **迭代修改**：讓 Codex 在瀏覽器中對照 DESIGN.md 截圖列出 5 個問題再逐項修改，禁止直說「重新做」
- **Cowart 無限畫布**：把參考截圖、生成頁面截圖、素材放在同一畫布對比，圈出問題後讓 AI 修改

## 可行動事項

- [ ] 下次做網頁前先讓 Codex 輸出 DESIGN.md，確認後再開始實作
- [ ] 嘗試用 design-taste-frontend Skill 對現有頁面去除 AI 味

## 原文整理

- 錯誤示範：「幫我做一個高級感個人網站」→ AI 給深色背景 + 紫藍漸變 + 功能卡 + AI 標籤
- 正確做法：先說「請整理 DESIGN.md，確認後再寫頁面」
- 素材問題往往比布局問題更影響質感：首屏圖、頭像、mockup、背景圖、圖標都可用內置 Imagen 生成
- 完整提示詞：第一步 DESIGN.md → 第二步確認 → 第三步實作 → 第四步在瀏覽器中截圖檢查
