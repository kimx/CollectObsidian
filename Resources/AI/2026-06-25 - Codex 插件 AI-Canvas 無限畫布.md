# 📎 Codex 插件 AI-Canvas 無限畫布

## 摘要

> 作者 @binghe 以 tldraw 開源庫為基礎，開發了 AI-Canvas 這個 Codex 插件。它讓 Codex 具備無限畫布能力，核心價值在於把畫布延伸成電商套圖、品牌物料生成的工作台，而不只是修圖工具。六個 Skill 工作流覆蓋了 95% 的常見圖片生成需求。

## 重點

- AI-Canvas 基於開源 tldraw，作者從零重新架構，非抄襲第三方程式碼
- 安裝方式：在 Codex 新對話輸入「帮我安装这个插件，网址是 https://github.com/binghe1980/AI-Canvas」
- 啟動後在側邊欄開啟畫布，可隱藏原 Codex 側邊欄擴大作業空間
- 六大 Skill：小紅書封面（3:4）、YouTube 封面（16:9）、產品營銷組圖、Logo 與品牌、營銷宣傳冊、一鍵跨平台適配
- 提交 Skill 後在任務記錄區出現狀態，回到 Codex 對話說「处理 Skill！」即可出圖

## 可行動事項

- [ ] 安裝 AI-Canvas 插件，測試小紅書封面或 YouTube 封面 Skill 工作流。
- [ ] 試驗外部生圖 → 導入畫布 → 二次編輯的流程，評估 Token 節省效果。

## 原文整理

- 插件靈感來自推特博主鍾二信，作者在六月 20 號前獨立逆向設計並開源
- 四個操作區域：尺寸區、上傳圖片、Skill 畫板、任務記錄區
- 小紅書封面：選圖→選 Skill→填寫內容類型與標題→提交，直出含字體版式的完整封面
- 電商產品組圖支援 Amazon A+、Shopify、Meta 廣告、Google 展示廣告等多種格式
- 作者有 20 年電商從業經驗，Skill 設計融合實際業務邏輯
