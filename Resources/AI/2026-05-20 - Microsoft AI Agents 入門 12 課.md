# 📎 Microsoft AI Agents 入門 12 課

## 摘要

> 這份微軟官方免費課程整理了 AI Agent 開發從概念到實作的核心路徑，並提供影片與程式碼範例。對想從 Prompt 使用者進階到 Agent 系統實作者，是一套可直接上手的學習地圖。

## 重點

- 課程主題從入門、設計模式到生產部署
- 涵蓋 MCP、Tool Use、Agentic RAG 等主題
- 支援多語系，包含繁體中文教材
- 每課有教學影片與對應程式碼
- 使用 Microsoft Agent Framework 與 Foundry

## 可行動事項

- [ ] 先完成 Intro、Frameworks、Design Patterns 三課並記錄學習筆記。

## 原文整理

- 內容推薦 `microsoft/ai-agents-for-beginners` 作為入門資源，強調其完整課綱與高星數社群關注。
- 課程包含多個實作導向單元，例如 Tool Use、Planning、Multi-Agent、Context Engineering 與 Security。
- 官方提供多語系翻譯與持續更新，適合邊學邊做專案驗證。
- 專案以 Microsoft Agent Framework 與 Azure AI Foundry Agent Service 為主要技術路線。
