# 📎 Claude／GPT 反討好提示詞

## 摘要

> 這篇整理了一段可直接放入 `Claude.md` 或 `Agents.md` 的提示詞，用來降低模型的討好傾向。它要求模型直接、精準、嚴格核查事實，並在需要時對使用者提出挑戰。

## 重點

- 先把模型定位成世界級專家
- 強調不能幻覺、不能編造、要自我驗證
- 允許更強硬、更有爭辯性的回答風格
- 明確排除客服、醫療與教育等情境
- 對研究與技術判斷很有用

## 可行動事項

- [ ] 把提示詞加入你的 `Claude.md` 或 agent 設定檔。
- [ ] 觀察它是否讓技術判斷變得更直接。

## 原文整理

- 文章提供中文翻譯版提示詞全文。
- 提示詞的四個層次是：專家角色、嚴格事實核查、語氣解放、政治正確豁免。
- 核心目標是減少模型過度圓融、避免講空話。
- 使用前要先判斷任務是否真的適合這種語氣。
