# 📎 Markdown 給 AI HTML 給人看

## 摘要

> 這篇內容強調 AI 產出格式不該只看習慣，而要看「給誰讀」。Markdown 適合模型讀寫效率，HTML 則更適合人類理解與互動，兩者應該分工搭配。

## 重點

- HTML 能提供更完整的視覺與互動表達
- Markdown 對 LLM 仍是高效率輸入格式
- 實測多數場景下 HTML 可讀性更好
- 關鍵不是替代，而是輸出對象分流
- 可用單一 HTML 檔承載豐富展示內容

## 可行動事項

- [ ] 針對常用 AI 報告模板，新增一版 HTML 視覺化輸出。

## 原文整理

- 文章引用社群討論指出「HTML is the new markdown」的趨勢，並聚焦格式選擇背後的實務價值。
- 內容比較 Markdown 與 HTML：Markdown 簡潔、token 友善；HTML 具備版面、色彩、互動等優勢。
- 文中提到多種應用場景，如 PR 差異檢視、方案比較、簡報與儀表板，都更適合 HTML 呈現。
- 核心結論是雙軌輸出：AI 工作流偏 Markdown，人類閱讀偏 HTML。
