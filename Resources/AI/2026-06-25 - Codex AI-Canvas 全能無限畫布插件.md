# 📎 Codex AI-Canvas 全能無限畫布插件

## 摘要

> 作者 binghe 基於 tldraw 開源庫，獨立為 Codex 開發了 AI-Canvas 無限畫布插件。插件整合六種圖片生成 Skill，涵蓋社群媒體封面、電商套圖到品牌設計等場景，讓 Codex 從改圖工具升級為完整的視覺工作流平台。

## 重點

- 以 tldraw 為基礎，實現無限畫布與「指哪改哪」功能
- 六種 Skill 工作流覆蓋 95% 常見圖片生成需求
- 支援本機圖片上傳、拖拽導入，減少不必要的 Token 消耗
- 操作入口簡單：@AI Canvas 即可喚起畫布；「處理 Skill！」即可執行
- 使用尺寸區、Skill 面板、任務記錄區三個核心區域完成工作流

## 可行動事項

- [ ] 在 Codex 或 Claude Code 中安裝 AI-Canvas 插件（`帮我安装这个插件，网址是 https://github.com/binghe1980/AI-Canvas`），測試一個小紅書封面或 YouTube 封面 Skill。

## 原文整理

- 作者用五小時從 tldraw 開源庫逆推出插件設計邏輯並完成初始版本
- 無限畫布的最大價值在於批量生成電商套圖、短劇分鏡、亞馬遜套圖等複合視覺素材
- 六個 Skill 均為作者根據 20 年電商從業經驗設計，包含完整的設計尺寸與業務邏輯
- 安裝流程：請 Codex 安裝 → @AI Canvas 喚起 → 選擇 Skill → 提交給 Codex 生成
