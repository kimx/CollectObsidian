# 📎 Codex 插件 AI-Canvas 全能無限畫布發布

## 摘要

> 這篇貼文介紹 AI-Canvas 如何把 Codex 變成可視化圖片工作台。核心價值不在單次修圖，而是把多種設計場景（社群封面、品牌、電商素材）封裝成可重複執行的 Skill 流程。

## 重點

- 無限畫布可作為圖片任務的統一操作介面，集中處理尺寸、素材與任務狀態。
- 支援外部生圖後再導入編輯，避免每次都消耗模型 Token 重新生成。
- Skill 工作流覆蓋社群封面、產品圖、品牌視覺與跨平台素材適配。
- 透過「提交給 Codex」可把畫布操作轉成可執行任務，降低手動溝通成本。

## 可行動事項

- [ ] 在常用 AI 編程環境安裝 AI-Canvas，並以一組真實素材驗證完整工作流與輸出品質。

## 原文整理

- 作者說明插件靈感來自社群討論，並以 tldraw 為基礎重新設計流程。
- 文章示範插件安裝、畫布啟動、Skill 面板操作與任務提交方式。
- 六類 Skill 對應常見商務圖像需求，目標是提高生圖效率與一致性。
- 延伸方向包含代理 API 模式，讓畫布可接入更多外部服務。
