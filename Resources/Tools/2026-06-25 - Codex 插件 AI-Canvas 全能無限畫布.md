# 📎 Codex 插件 AI-Canvas 全能無限畫布

## 摘要

> AI-Canvas 是一個開源 Codex 插件，核心功能是為 Codex 加上無限畫布，讓使用者能在畫布上直接標注、上傳、生成圖片，並透過 6 個內建 Skill 工作流一鍵生成各類業務圖像素材，從社群媒體封面到電商套圖全部涵蓋。

## 重點

- 無限畫布基於開源 **tldraw**，可在 Codex 側邊欄直接開啟作為工作區
- 6 個 Skill 工作流：小紅書封面（3:4）、YouTube 封面（16:9）、產品營銷組圖、Logo 與品牌、營銷宣傳冊、一鍵跨平台適配
- 流程：提交 Skill 任務 → 任務記錄區出現狀態 → 回到 Codex 對話框說「處理 Skill！」→ 等待出圖
- 可外部生圖後導入畫布，省去 Codex Token；Web API 代理功能正在開發中
- 安裝方式：讓 Codex 幫你安裝 `https://github.com/binghe1980/AI-Canvas`

## 可行動事項

- [ ] 讓 Codex 安裝 AI-Canvas 插件並開啟無限畫布
- [ ] 選一個業務場景（如小紅書封面或電商套圖），走完完整的 Skill 工作流

## 原文整理

- 作者花 5 小時從推特博主 @鍾二信 的影片倒推出插件設計邏輯，自行重新架構實作
- 無限畫布的擴展性：電商套圖、產品詳情頁、短劇分鏡、UGC 宣傳圖等場景
- 畫布介面重點區域：尺寸區、上傳圖片、Skill 畫板、任務記錄區
- 6 個 Skill 各有對應的輸入欄位（內容類型、主標題、風格、目標受眾等），直出帶字體版式的完整圖
