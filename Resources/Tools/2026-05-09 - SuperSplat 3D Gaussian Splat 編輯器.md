# 📎 SuperSplat 3D Gaussian Splat 編輯器

## 摘要

> SuperSplat 是一款可在瀏覽器直接使用的開源 3D Gaussian Splat 編輯器，主打檢視、編輯、優化與發佈。它不需要額外安裝桌面程式，適合想快速處理 splat 資料或建立展示流程的人。

## 重點

- 完全基於 web technologies，直接在瀏覽器運作
- 支援 inspect、edit、optimize、publish
- 提供 user guide 與線上 demo
- 本地開發流程明確，Node.js 18 以上即可
- 也有 locale 與翻譯擴充機制

## 可行動事項

- [ ] 打開線上版，確認實際操作是否符合需求。
- [ ] 若要本地開發，再依官方步驟建立 Node 環境。

## 原文整理

- 專案首頁提供線上 editor、User Guide、Blog 與 Forum 連結。
- 本地開發只要 clone repo、安裝依賴、執行 `npm run develop`。
- 官方也說明如何新增語系與測試翻譯。
- 文件的核心訊息是：這是一個可直接上手的瀏覽器型工具，而非需要安裝的桌面軟體。
