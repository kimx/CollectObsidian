# 📎 ShareX 免費開源截圖工具

## 摘要

> ShareX 是一款專為 Windows 設計的免費開源工具，主打螢幕截圖、錄影與快速分享。它支援快捷鍵操作、自動上傳、多種目的地整合，以及 OCR、滾動截圖等進階功能。若經常需要整理畫面、回報問題或分享操作流程，ShareX 能明顯提升效率。

## 重點

- **免費開源的 Windows 螢幕截圖與錄影工具**：完全免費且開放原始碼，無廣告無限制
- **支援單鍵截取任何螢幕區域並快速分享**：可自訂快捷鍵，截圖後立即上傳或編輯
- **內建圖片編輯、OCR、滾動截圖等進階功能**：提供豐富的圖片後製效果與 OCR 文字辨識
- **可自動上傳至多種雲端平台與自訂上傳器**：支援 Amazon S3、Google Cloud Storage、Cloudflare R2 等
- **提供豐富的快捷鍵與工作流程自動化**：可設定動作（Actions）自動執行一系列任務

## 原文整理

ShareX 是一款專為 Windows 設計的免費開源螢幕截圖、檔案分享與生產力工具。

### 主要功能

**螢幕擷取**
- 快捷鍵快速截取螢幕任何區域
- 支援全螢幕、視窗、區域、滾動截圖等多種模式
- 可錄製螢幕影片

**檔案上傳**
- 自動上傳圖片、文字及各類檔案
- 支援超過 80 種上傳目的地
- 可自訂上傳器（Custom Uploader）
- 支援主流雲端服務：Amazon S3、Google Cloud Storage、Cloudflare R2

**進階功能**
- **圖片效果**：內建豐富的圖片後製效果
- **動作（Actions）**：可設定一系列自動化任務
- **OCR 文字識別**：從圖片中提取文字
- **滾動截圖**：自動捲動頁面並拼接完整截圖
- **快捷鍵自訂**：所有功能皆可綁定快捷鍵
