# 📎 html-anything Agent HTML 生成工具

## 摘要

> 這則內容介紹 html-anything 的開源發布，定位是把 Agent 產出的資料轉成高品質 HTML。重點在多技能、多輸出格式與跨多種 code agent 的相容性，適合做展示與分享。

## 重點

- html-anything 已正式開源
- 強調可將任意資料轉成高品質 HTML
- 提供 75 套 Skills 與 9 種輸出格式
- 可搭配 claude code、codex 等 agent 使用
- 定位在提升內容展示與交付質感

## 可行動事項

- [ ] 找一份既有 Agent 產出，實測轉成 HTML 的展示效果。

## 原文整理

- 作者宣布 html-anything 正式開源，主打可 1:1 呈現熱門 HTML 效果。
- 工具目標是讓 Agent 能把各種資料轉為高設計水準的 HTML。
- 內容提到開發投入約 3 天、程式碼約 1 萬 5 千行。
- 功能面強調支援 75 套 Skills、9 種輸出格式。
- 相容性上可搭配多種 code agent（如 claude code、codex 等）。
